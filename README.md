# Лабораторная работа 6. Типы грунта

React-приложение для просмотра и ведения справочника типов грунта. Дополняет [бэкенд ЛР4](https://github.com/KirillD06/DavydovKirill_labs_5_sem/tree/lab4-auth-swagger).

## Запуск

Для работы с данными запустите NestJS на порту 3004 по инструкции бэкенда. MinIO по умолчанию доступен на порту 9000.

В каталоге фронтенда выполните:

```bash
npm ci
npm run dev
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Если веб-сервис недоступен, гостю показываются учебные карточки из проекта. Для других адресов веб-сервиса и MinIO задайте `VITE_API_TARGET` и `VITE_MEDIA_TARGET`.

## Страницы

| Страница | Адрес | Поля и действия |
| --- | --- | --- |
| Плитка | `/soil_types` | Фото, название, коэффициент разрыхления, плотность и количество лайков. «Показать» применяет верхнюю границу коэффициента, «Сбросить» сбрасывает фильтр. Нажатие открывает карточку. «Удалить» доступно владельцу. |
| Лента | `/soil_types/feed` | Видео, название, описание, две характеристики и счётчик лайков. «Ещё» раскрывает описание. Стрелка открывает следующий грунт. Сердце ставит или снимает лайк после входа. |
| Добавление | `/soil_types/draft` | Создатель вводит название и при желании прикладывает фото и видео. «Далее» создаёт черновик. «Опубликовать» отправляет описание, коэффициент разрыхления и плотность. |
| Вход | `/users/login` | Логин и пароль. «Создать аккаунт» открывает форму регистрации. После входа меню показывает «Выход» и открывает «Добавление». |

Подробная карточка `/soil_types/:id` показывает видео, полное описание и характеристики выбранного грунта. Кнопка «Каталог» возвращает к прежнему фильтру.

## Запросы и состояние

Vite проксирует `/api` в NestJS и `/s3/soil-types/` в MinIO. Команда `npm run generate:api` обновляет клиент Axios из Swagger на `http://127.0.0.1:3004/api-json`. Thunk-функции грунтов вызывают сгенерированный клиент.

Redux хранит коэффициент фильтра, текущего пользователя и состояния запросов. Вход и выход вызывают Axios напрямую и передают результат в Redux. Выход сбрасывает фильтр. После перезагрузки Redux стартует в гостевом режиме, а HttpOnly cookie остаётся в браузере до завершения сессии.

npm run build
