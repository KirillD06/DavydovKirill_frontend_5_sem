# Лабораторная работа 5. Типы грунта

Каталог и видеолента типов грунта для подбора исходных данных при расчёте объёма котлована. Приложение написано на React и TypeScript с React-Bootstrap и Vite. Карточки, изображения и видео загружаются из проекта.

## Запуск

В корне проекта выполните:

```bash
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для сборки используйте `npm run build`.

## Страницы

| Страница | Адрес | Поля и действия |
| --- | --- | --- |
| Плитка | `/soil_types` | В каждой карточке видны фото, название, коэффициент разрыхления, плотность и количество лайков. Слайдер задаёт максимальный коэффициент от 1,10 до 1,50 с шагом 0,01. «Показать» применяет фильтр, «Сбросить» возвращает весь список. Карточка открывается по нажатию. |
| Лента | `/soil_types/feed` | Видео, название, описание, коэффициент разрыхления, плотность и количество лайков. «Ещё» и «Скрыть» разворачивают и сворачивают описание. Стрелка переключает грунты по кругу, «Подробнее о грунте» открывает карточку. |
| Карточка грунта | `/soil_types/:id` | Видео, название, полное описание, коэффициент разрыхления, плотность и количество лайков. «Каталог» возвращает в плитку с прежним фильтром. «Следующий грунт» открывает следующую карточку в отфильтрованном списке или в полном списке, если текущей карточки нет среди результатов. |

В нижнем меню доступны «Лента» и «Плитка». Кнопки «Добавление» и «Вход» отключены в гостевом режиме.
